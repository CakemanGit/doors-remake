# DOORS Remake 👁️

An atmospheric 3D horror game inspired by Roblox DOORS, built using React Three Fiber, TypeScript, and Vite. 

## 🚀 How to Play (PC Version)
1. Go to the **Releases** section on the right side of this GitHub page.
2. Download the latest `DOORS_Remake_v1.0.zip` file.
3. Extract the ZIP archive to any folder on your computer.
4. Open the extracted folder, find **`DOORS Remake.exe`**, and double-click to play!

## 🛠️ Controls
* **WASD** / Arrow Keys — Move around the hotel rooms
* **Mouse** — Look around (Pointer Lock engages automatically)
* **LMB (Left Click)** / **E** — Interact with doors and hide in wardrobes
* **Flashlight** — Turn the light source on/off via the HUD button
